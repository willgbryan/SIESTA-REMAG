# Sparse SCF ownership contract

An opt-in integration now connects the qualified resident grid to device Hamiltonian seeds, scalar consumers and stable Pulay. The adapter compiles on CUDA and its coupled ownership checks pass. Full SCF integration remains **unqualified** after the first batch exposed an overly strict mixer guard. The zero-transfer target and accepted evidence remain in [GPU_RESIDENCY.md](GPU_RESIDENCY.md).

Pinned upstream `siesta_forces.F90` uses Hamiltonian mixing in the accepted corpus. Its order is `compute_DM` → density residual → `setup_hamiltonian` → Hamiltonian residual → charge/energy → convergence → optional mixing. The initial `setup_hamiltonian(0)` happens before the SCF loop. On convergence, mixing is skipped. Final work needs both the last output H and the previous mixed H that generated the final density.

| State | Owner and required transition |
| --- | --- |
| Initial H/D/E | Stage after the original pre-step and before the first diagonalization; initial setup is outside steady state |
| Mixed H and Hold | Save the generator before constructing H(D); the eigensolver borrows mixed H until its declared H/S lifetime ends |
| D/E and previous D/E | Preserve previous arrays before the density builder reuses its accumulation buffers; finish normalization before publishing new density |
| Kinetic/nonlocal/SOC arrays | Geometry-owned immutable inputs, staged once and invalidated with geometry/sparsity changes |
| H(D) | Initialize device seeds, accumulate the resident grid contribution, then add offsite SOC in upstream order |
| Energy seeds | Merge geometry constants, Hamiltonian energy reductions, grid results and occupation entropy on device; do not reintroduce scalar uploads through launch arguments |
| H residual and charge/energy results | Reduce using full sparse capacity for traces/residuals and topology-selected entries for charge; preserve SOC hermitification and NC factors |
| Pulay history | Fixed all-component stable-Pulay configuration within an epoch; reset on a new geometry even when dimensions/addresses are unchanged |
| Final state | Export explicitly for the remaining original force/stress and analysis consumers, then migrate those consumers in a separate phase |

The patch changes `compute_dm.F`, `setup_hamiltonian.F`, `siesta_forces.F90`, `mixer.F`, `scfconvergence_test.F` and all six density builders. CPU copies and zero-fills of D/E, Hamiltonian seeding, SOC additions, residual/energy/charge reductions and optional spin printing now use an explicit device-owner branch. The H/S bridge borrows the current device H; the grid consumer accumulates into device H. Host identity checks validate lifetimes without scanning array contents in normal operation; debug snapshots detect unexpected writes.

Each borrower needs explicit shape, spin convention, geometry epoch and permitted stage. Missing, duplicate or stale producers/consumers must fail rather than silently upload old host data. Failed device calculations must preserve a reportable error and prevent the next scientific iteration from consuming invalid state. Final export must recover the original arrays used by `post_scf_work`, including Hold.

Initial supported integration should match the measured corpus: serial diagonalization, Hamiltonian mixing, all spin components, one stable-Pulay mixer, fixed weights, no mixer switching/restart, `SCF.MixAfterConvergence=false`, upstream first-step mixing behavior, and the existing periodic built-in PBE grid scope. Additional matrix consumers, in-SCF exports, applied fields, DFT+U, other energy corrections and alternate mixing policies require explicit implementation or rejection. Preserve the upstream convergence criteria; reducing transfers does not authorize changing numerical tolerances or iteration limits.

Temporary scalar exports may qualify a bulk-array milestone if measured and disclosed. They cannot qualify strict loop residency. The remaining cuSOLVER status transfers and device convergence/termination problem remain independent requirements after H/D/E ownership closes.

## First adapter boundary

A practical first adapter can keep upstream's host convergence decision temporarily while removing H/D/E array round trips. Prepare the owner after `setup_hamiltonian(0)` has built the initial H, before the SCF marker. Stage geometry constants, initial H/D and the enabled mixer configuration there. Avoid reading an uninitialized initial Escf when EDM convergence is disabled; the first computed E becomes the next iteration's old E. Reset Pulay for every electronic cycle, even if a geometry epoch is reused.

The owner should progress through ready → solving → density-ready → seeded → grid-writing → grid-ready → H-ready → reduced → mixed. Save Hold and old D/E at iteration entry. `remag_dm_finish` can publish its normalized device arrays into the owner and leave host outputs opaque. `remag_resident_density` should then obtain the matching owned D directly; the H/S bridge should borrow mixed H, and the grid bridge should borrow the seeded H output. After grid accumulation, the seed plan commits offsite SOC. Skipped or repeated stages must fail. A converged cycle ends at reduced, while an unconverged cycle advances through mixed.

The scalar plan should consume a device energy-seed record assembled from immutable Ena/Eions/Emad/temperature, the three Hamiltonian reductions, the grid result (`Enascf=energies[4]`, `Enaatm=energies[3]`, `DUscf=energies[1]`, `Exc=energies[5]+energies[6]`) and the retained FD entropy. Exporting a compact scalar record can temporarily preserve upstream energy printing/convergence. It must report component errors as well as numerical values. The original SCF spin print should use the already-computed device charge result; other in-loop matrix-analysis options need explicit rejection until ported. The upstream `update_E0` bookkeeping can follow the returned kinetic/nonlocal/SOC reductions, avoiding a separate seed-energy download.

Call the device Pulay plan only in the original nonconverged mixing branch. A temporary scalar status readback is acceptable for this bounded array-ownership milestone, but must remain counted. End the lifetime after the post-SCF marker and before existing final consumers, restoring H, Hold, D, Dold and the required E/Eold arrays in explicit final exports. The current final-force path can then run unchanged while its separate device port is developed.

This adapter still leaves scalar readbacks, host convergence, repeated host topology preparation and final force/analysis work. Its evidence must not claim the strict target. Full upstream trajectories and ownership/error tests are required before any new path becomes qualified.

## Draft implementation and pending qualification

`native/sparse_state.cu` owns H/Hold/D/Dold/E/Eold and the residual. Production links the already qualified Hamiltonian, scalar and Pulay plans. `REMAG_RESIDENT_SCF=1` enables the adapter; `--resident-scf --sparse-state-ablation` runs it with a direct resident-grid control in the sequential Modal harness. Unsupported scientific consumers and mixing settings fail explicitly. All allocated host matrix arrays stay opaque within a lifetime and are restored after the post-SCF marker. Host Eold is optional when EDM convergence is disabled; its device history still exists.

The draft exports a **144-byte scalar/error record each iteration** and **four bytes of Pulay status when mixing**. Existing grid (224-byte), occupation (32-byte), normalization and eigensolver scalar boundaries remain. Initial owner staging and the final matrix exports have separate accounting labels (five buffers when host Eold is absent, otherwise six). Runner gates require one of each producer/consumer per SCF iteration, exactly one preparation/export per cycle and no H/D/E or spectral array copies inside SCF. These are full-SCF acceptance gates; the first integrated batch fails before reaching SCF, so the array-residency milestone is not yet measured.
